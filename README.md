# Exam paper generator

本儲存庫保存國中自然科題庫的盤點結果與 AI 原創重製規格，供協作者與其他 AI 接手使用。本次只同步修訂的 Markdown，不連帶上傳本機尚未推送的原始題庫與樣卷；以下來源路徑描述本地工作資料，取得遠端規格不代表已取得這些來源檔案。

主要文件：

- `AI題庫重製規格與盤點_20260908.md`：題庫結構、以歷屆試題為主的素養命題方向、雙 sub agent 圖文分工、Word 正式交付與圖片位置驗證；流程已於 2026 年 9 月 10 日更新，原盤點統計保留。
- `分級題庫逐卷統計.csv`：各科、冊次、小節與難度的題型及圖表結構統計。
- `原始檔案清冊.csv`：本次盤點使用的相對路徑、檔案大小與雜湊值，方便核對來源版本。
- `example/`（本地來源，未隨本次同步）：原始題庫、歷屆試題與配對答案檔；實際命題須由資料持有人另行提供所選單元與歷屆原頁。
- `sample/biology/Book1/1-3進入實驗室/`（本地歷史樣卷，未隨本次同步）：含題目卷、解析卷、Markdown、HTML/SVG 圖稿、PNG 圖片與當時驗證資訊；不是已核准的命題或視覺標準，不能直接套用其中的題數及圖像流程。
- `SYNC_POLICY.md`：每次工作完成才檢查及同步實質差異，禁止獨立週期同步。

命題主要參考本地已核實的會考題：先用 111～115 年，再按需要補 104～110 年；它們決定題幹語氣、情境功能、證據推論及干擾項設計。96～103 年基測僅是會考材料不足時的備用來源，須完成影像／文字核對與理由記錄，不能主導命題或難度。`example/` 單元 Word 限定知識與難度，其他樣張為輔助。每題保留可定位會考檔案、年度題號與頁序的 `style_refs`；以題中資料支持判斷，不以故事長度或圖片數量宣稱素養。

新批次由兩個 sub agent 分工。A 在內部 `work/questions.draft.md` 完成題目及可編輯表格，答案解析另存 `work/answers.draft.md`；只在圖片為作答必要時，於插入位置留下含 JSON 的 `IMAGE_REQUEST` prompt 區塊，需求通過檢查後才啟動 B，無圖則不建立空任務。B 自動讀完整題目稿，依唯一 `asset_id` 生成圖片、驗證後在 `work/questions.illustrated.md` 原位置回填，成功的整個 prompt 區塊替換為圖片引用；題文及表格保持一致，共用圖只生成一次，不把答案卷傳給圖像模型。失敗保留工作稿需求並標記 failed，不能以空圖或占位交卷。`work/` 是主規格所定義的相應批次工作目錄簡寫，與正式 `output/` 分離。

主代理最後驗收並發布不含 prompt 的 `questions.md`、`questions.jsonl`，以及每批必交的 Word 題目卷與解析卷；內部工作稿與圖片處理紀錄和學生題本分離。Word 圖片依 `asset_id` 與 `anchor` 以 inline 方式插在正確題幹／共同素材後，須通過嵌入、段落順序、替代文字與逐頁渲染檢查。圖片使用可用 AI 圖像生成能力，精確資料圖與標籤由確定性工具補核；只有明確要求原生 SVG 時才啟用 SVG 規格，不固定使用 HTML／SVG。表格維持原生可編輯，圖片與表格都沒有最低配額。預設題數維持 10 題是非＋30 題單選＋題組 20 小題，其中至少 43 題使用題內新給證據完成判斷；批量前先交驗樣稿。

接手 AI 應先完整讀取本目錄規格，再讀 `example/` 對應單元與已核實的歷屆原頁；`sample/` 只輔助理解交付結構，不能取代最新流程或使用者樣稿驗收。

注意：題庫與歷屆試題可能涉及原始出版者的著作權；請只在你具有使用與分享權限的 GitHub 儲存庫中使用，並自行設定適當的儲存庫可見性。
